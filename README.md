# Basics-js

This repository contains basic JavaScript tutorials and examples covering fundamental concepts.

## Files

- `controllStmt.html` - Control statements in JavaScript
- `loops.html` - Basic loops
- `loopsAdv.html` - Advanced loop concepts
- `Object.js` - JavaScript objects
- `varVslet.html` - Difference between var and let

## Usage

Open the HTML files in a web browser to view the examples. The JavaScript file can be run in a Node.js environment or included in HTML files.
